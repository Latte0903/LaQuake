LaQuake는 Windows 플랫폼을 위한 지진 조기경보 수신 및 강력한 알림 도구입니다. [Wolfx(Wolfx.jp)](https://wolfx.jp/)를 핵심 데이터 소스로 사용하며, 지진파가 도착하기 전에 신속하고 눈에 띄는 경보 정보를 제공하고 상세한 지진 후 속보를 푸시하는 것을 목표로 합니다.

<img src="docs/LaQuake_view.png" alt="LaQuake 인터페이스 미리보기" width="100%">

## 🌟 핵심 기능

- **실시간 데이터 수신:** Wolfx API로부터 지진 조기경보(EEW) 및 지진 속보 정보를 밀리초 단위로 수신합니다.
- **전체 화면 강력 알림:** 설정한 경보 임계값이 트리거되면 항상 위에 표시되는 전체 화면 팝업과 경보음으로 중요한 정보를 놓치지 않도록 합니다.
- **경보 모의 훈련:** 방재 훈련, 교육 시연, 소프트웨어 설정 테스트를 위한 내장 지진 조기경보 시뮬레이션 기능을 제공합니다.
- **생태계 연동:** [EEWCN](https://www.bilibili.com/video/BV1Zs4y1g7un/)과 함께 사용하여 더욱 종합적인 방재 정보 모니터링 환경을 구축할 수 있습니다.
- **현대적인 UI:** Electron 기반으로 깔끔하고 부드러운 인터페이스와 낮은 시스템 리소스 점유율을 제공합니다.

## 💻 시스템 요구 사항

- 운영체제: Windows 10 / Windows 11(64비트)
- 네트워크 환경: 실시간 데이터 수신을 위해 기기가 항상 인터넷에 연결되어 있어야 합니다.

## ⚠️ 엄숙한 성명 및 면책 조항(필독)

본 소프트웨어를 사용하거나 이 저장소의 소스 코드를 열람하기 전에 다음 조항을 반드시 주의 깊게 읽고 동의해 주십시오. 소프트웨어를 사용하면 아래 모든 내용에 완전히 동의한 것으로 간주됩니다.

- **베타 버전 동의(Alpha):** 본 소프트웨어는 현재 Alpha 초기 테스트 단계로, 불안정, 기능 미완성, 크래시 또는 데이터 표시 오류가 발생할 수 있습니다. 개발자는 소프트웨어 결함이나 실행 중단으로 인한 직간접적 결과에 대해 책임지지 않습니다.
- **비영리 및 기부 거부 성명:** 본 소프트웨어는 완전히 무료인 개인 학습 및 연구 프로젝트이며, 어떠한 형태의 유료 결제, 후원, 멤버십 또는 기부도 받지 않습니다. 어떤 경로로든 유료 버전, 유료 대리 빌드, 후원을 요구하는 버전은 모두 사기이므로 속지 마시기 바랍니다.
- **저작권 및 오픈소스 라이선스 제한:** 본 프로젝트에는 현재 어떠한 오픈소스 라이선스도 적용되지 않으며, 공개된 소스 코드는 개인 학습과 코드 교류 목적으로만 제공됩니다. 상업적 이용, 재배포, 재패키징 판매, 소스 코드의 수정 및 파생물 제작은 엄금됩니다.
- **전파 및 방송 제한:**
  - Bilibili, 더우인(Douyin), Twitch, 더우위(Douyu) 등 공개 플랫폼에서 본 소프트웨어의 화면을 라이브 방송하는 것을 엄금합니다.
  - 소프트웨어 내 경보 정보를 스크린샷, 화면 녹화 등의 형태로 소셜미디어에 광범위하게 전파하는 것을 엄금합니다.
- **데이터 정확성 면책:** 공개 API가 제공하는 데이터에는 지연, 오차 또는 오류가 있을 수 있습니다. 개발자는 Wolfx API가 푸시하는 내용의 정확성과 적시성에 대해 어떠한 법적 책임도 지지 않으며, 모든 정보는 현지 공식 지진 관리 부서의 발표를 기준으로 삼으시기 바랍니다.
- **모의 기능 면책:** 소프트웨어 내 “경보 시뮬레이션” 기능은 개인/내부 방재 사전 훈련과 시연용으로만 제공됩니다. 허위 경보 유포, 공포 조성, 장난 등 본 기능의 오용으로 인한 사회적 영향이나 법적 결과는 전적으로 사용자 본인이 책임지며 개발자와 무관합니다.
- **연령 및 사용 자격:** 본 소프트웨어를 사용하기 전에 거주 국가 또는 지역의 법적 성년 연령에 도달해야 합니다. 미성년자는 반드시 보호자의 동반 하에 방재 지식을 학습해야 하며, 단독으로 본 소프트웨어를 조작하지 마십시오.
- **법적 관할:** 본 소프트웨어 또는 그 소스 코드 사용으로 발생하는 모든 법적 분쟁은 개발자가 소재한 중화인민공화국 대륙 지역 법원에서 해결됩니다.
- **특별 감사:** 본 소프트웨어의 일부 디자인 아이디어와 설정 항목은 EEWCN을 참고했습니다. 작성자 페이지: [lxfly2000](https://github.com/lxfly2000).

## 🛠️ 빌드, 설치 및 실행(학습 목적 전용)

### 1. 글꼴 의존성 준비(빌드 전 필독)

UI 미관과 표시 적합성을 위해 본 소프트웨어는 빌드 및 실행 시 특정 글꼴에 의존합니다. 빌드하기 전에 [OPPO 공식 웹사이트](https://www.coloros.com/article/A00000074/)에서 OPPO SANS 4.0 글꼴을 다운로드하고, 압축을 푼 글꼴 파일을 프로젝트 루트의 `Fonts` 폴더에 넣어 주십시오. 글꼴 파일이 없으면 빌드 실패나 UI 레이아웃 오류가 발생할 수 있습니다.

### 2. 빌드 및 실행 절차

1. 저장소를 로컬에 복제합니다.

   ```bash
   git clone https://github.com/Latte0903/LaQuake.git
   ```

2. 프로젝트 디렉터리로 이동합니다.

   ```bash
   cd LaQuake
   ```

3. 다운로드한 OPPO SANS 4.0 글꼴 파일을 `Fonts` 폴더에 넣었는지 확인합니다.
4. 프로젝트 의존성을 설치합니다.

   ```bash
   npm install
   ```

5. 로컬에서 개발 환경을 시작하여 테스트합니다.

   ```bash
   npm start
   ```

## ⚖️ 법적 규정 준수 및 성명

본 소프트웨어는 《중화인민공화국 지진방재경감법》《중화인민공화국 민법전》및 관련 법령을 엄격히 준수합니다.

- “국가가 지진 예보 의견에 대한 통일 발표 제도를 실시한다”는 지진방재경감법 제29조 관련 규정에 따라, 본 소프트웨어는 제3자 데이터 소스(Wolfx)의 수신 및 로컬 화면 표시 도구일 뿐이며, 지진 모니터링·예보 자격을 갖추고 있지 않고 그렇게 주장하지도 않습니다. 소프트웨어에 표시되는 정보는 공식 결론을 대표하지 않으며, 모든 지진 조기경보와 속보는 반드시 중국지진국 및 각 지방 지진 관리 부서의 공식 권위 발표를 기준으로 삼으시기 바랍니다.
- 《중화인민공화국 민법전》및 사이버 보안 관련 법령에 따라 사용자는 성실신용 원칙과 공서양속을 준수해야 하며, 본 소프트웨어와 부가 기능(경보 시뮬레이션 등)을 이용해 루머를 유포하거나 거짓 위험을 꾸며내고 사회적 공황을 일으키거나 사회 공공 이익을 해치는 행위는 엄금됩니다. 개발자는 본 소프트웨어를 이용한 모든 위법·위규 활동에 단호히 반대하며 관련 법 집행 부서의 조사에 협조할 권리를 보유합니다.
