LaQuake 是一款專為 Windows 平台打造的地震預警接收與強提醒工具。本軟體以 [Wolfx (Wolfx.jp)](https://wolfx.jp/) 為核心資料來源，致力於在地震波到達前為使用者提供及時、醒目的預警資訊，並支援詳細的震後速報推送。

<img src="docs/LaQuake_view.png" alt="LaQuake 介面預覽" width="100%">

## 🌟 核心功能

- **即時資料接入：** 毫秒級接收來自 Wolfx API 的地震預警 (EEW) 與地震速報資訊。
- **全螢幕強提醒：** 觸發設定的預警門檻時，全螢幕強制置頂彈窗並播放警報音，確保關鍵資訊不被錯過。
- **預警模擬演練：** 內建地震預警模擬功能，專為防震減災演練、教育示範與軟體設定測試設計。
- **生態協同：** 支援與 [EEWCN](https://www.bilibili.com/video/BV1Zs4y1g7un/) 配合使用，建構更全面的防災資訊監測流。
- **現代化 UI：** 基於 Electron 建構，介面簡潔流暢，低系統資源占用。

## 💻 系統需求

- 作業系統：Windows 10 / Windows 11（64 位元）
- 網路環境：需保持裝置全程連網以接收即時資料。

## 🛠️ 編譯、安裝與執行（僅供學習）

### 1. 字型依賴準備（編譯前必看）

出於介面美觀與 UI 适配需要，本軟體在編譯和執行時依賴特定字型。執行編譯建構前，請自行前往 [OPPO 官網](https://www.coloros.com/article/A00000074/) 下載 OPPO SANS 4.0 字型，並將解壓縮後的字型檔案放入專案根目錄下的 `Fonts` 資料夾。若缺少該字型檔案，可能導致編譯失敗或介面排版錯亂。

### 2. 建構與啟動步驟

1. 複製本儲存庫到本機：

   ```bash
   git clone https://github.com/Latte0903/LaQuake.git
   ```

2. 進入專案目錄：

   ```bash
   cd LaQuake
   ```

3. 確保已將下載好的 OPPO SANS 4.0 字型檔案放入 `Fonts` 資料夾。
4. 安裝專案相依套件：

   ```bash
   npm install
   ```

5. 在本機啟動開發環境進行測試：

   ```bash
   npm start
   ```
