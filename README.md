# LaQuake 地震预警与速报

🚀 **基于 Electron 架构的 Windows 桌面级地震预警与速报软件 (Alpha 测试版)**

LaQuake 是一款专为 Windows 平台打造的地震预警接收与强提醒工具。本软件以 [Wolfx (Wolfx.jp)](https://wolfx.jp/) 为核心数据源，致力于在地震波到达前为用户提供及时、醒目的预警信息，并支持详细的震后速报推送。

## 🌟 核心功能

- **实时数据接入：** 毫秒级接收来自 Wolfx API 的地震预警 (EEW) 与地震速报信息。
- **全屏强提醒：** 在触发设定的预警阈值时，支持全屏强行置顶弹窗与警报音，确保关键信息不被错过。
- **预警模拟演练：** 内置地震预警模拟功能，专为防震减灾演练、教育演示与软件配置测试设计。
- **生态协同：** 完美支持与 [EEWCN](https://www.bilibili.com/video/BV1Zs4y1g7un/) 配合使用，构建更全面的防灾信息监测流。
- **现代化 UI：** 基于 Electron 构建，界面简洁流畅，低系统资源占用。

## 💻 系统要求

- **操作系统：** Windows 10 / Windows 11 (64-bit)
- **网络环境：** 需保持设备全程联网以接收实时 API 推送。

## 🛠️ 编译、安装与运行 (仅供学习)

### 1. 字体依赖准备（编译前必看）

出于界面美观与UI适配原因，本软件在编译和运行时需要特定字体支持。**在执行编译构建前，请务必自行前往** **[OPPO 官网](https://www.coloros.com/article/A00000074/)** **下载 OPPO SANS 4.0 字体，并将其解压后的字体文件放入项目根目录下的** **`Fonts`** **文件夹中。** 如果缺失该字体文件，可能会导致编译失败或界面排版错乱。

### 2. 构建与启动步骤

1. 克隆本仓库到本地：

   Bash
   ```
   git clone https://github.com/Latte0903/LaQuake.git

   ```
2. 进入项目目录：

   Bash
   ```
   cd LaQuake

   ```
3. 确保已将下载好的 **OPPO SANS 4.0** 字体文件放入 `Fonts` 文件夹中。
4. 安装项目依赖：

   Bash
   ```
   npm install

   ```
5. 在本地启动开发环境进行测试：

   Bash
   ```
   npm start

   ```
